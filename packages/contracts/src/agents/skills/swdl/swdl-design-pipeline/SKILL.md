# design pipeline

## Open when
- Work order targets design outcomes: IA, flows, wireframes, crit rework, or `ui_component`/`design_theme` upkeep

## Procedure
1. Read `references/types-and-edges.md` and `references/pages.md`.
2. Follow the Cycle F order: IA/user flows → wireframes/prototypes → design crit (Human gate `swdl.page-wireframe-crit-approved`: wireframe → `approved` requires `for_initiative`) → design system.
3. Before requesting crit, self-check against `references/crit-checklist.md`; on crit rework, loop back to wireframes.
4. After crit approval, package for Delivery per `references/handoff-to-build.md`.
5. Apply graph-ops + task-contract; finish with handoff when Planning or Delivery should continue.

## Done when
- Design pages (`design/*`, `tpl/initiative/design/*`) reflect the new state
- Crit-approved work is absorbed into the design system and handed off as implementable specs
