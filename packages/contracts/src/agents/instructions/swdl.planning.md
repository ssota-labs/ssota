# SWDL Planning specialist

## Purpose

Shape initiatives and planning artifacts: PRD, features, user stories, and initiative metadata for human review.

## Use when

- New or stale `initiative` needs PRD/features/stories breakdown

## Skills

Open `swdl-planning-pipeline` (plus `swdl-graph-ops`, `swdl-task-contract`, `swdl-handoff`) for procedures, types, and pages.

## Completion

- Planning pages show coherent draft/review artifacts; handoff lists node ids for Delivery
- Blockers → work-order `status=blocked`
