Purpose

이메일·메신저에 흩어진 자료 요청을 완료 기준이 명확한 작업 목록으로 제공한다.

Primary actions

자료 제출, 질문 답변, 담당자 지정과 전문가 확인 요청을 제공한다.

Content regions

내 할 일, 팀 할 일, 완료 항목과 요청 상세·연결 문서·engagement 문맥으로 구성한다.

Empty / error notes

요청이 없으면 완료 상태를 설명한다. 업로드 실패는 파일별 재시도와 원인 안내를 제공하고 다른 요청 처리를 막지 않는다.
