범용 그래프 중심 제품을 고객·전문가가 실제 업무를 수행하는 Company Workspace로 전환하는 첫 UX 기반 릴리즈
PRDs
PRD-company-workspace-ux
Features
F-company-workspace-shell F-customer-workspace F-expert-workspace

Theme

데이터 구조를 그대로 노출하는 범용 그래프 콘솔이 아니라, 고객에게는 회사의 상태와 다음 행동을, 전문가에게는 검토 큐와 근거를 제공하는 업무 공간을 만든다.

In scope

  • 고객용 Company Workspace와 전문가용 Expert Workspace의 명시적 분리
  • 회사 선택, 전역 검색, 활동·알림을 공유하는 공통 애플리케이션 셸
  • 고객 IA: Home, Requests, Engagements, Reports, Documents, Company Data
  • 전문가 IA: Client Portfolio, Review Queue, Engagement Workspace
  • 도메인 상세 화면이 따를 Overview · Records · Workbench · Detail 페이지 문법

Out of scope

  • Finance, Legal, HR, Equity의 상세 업무 흐름과 정본 스키마 구현
  • 외부 데이터 수집 파이프라인과 회계·계약 규칙 구현
  • 그래프 데이터 마이그레이션 또는 기존 Console의 즉시 제거
  • 고객별 자유 페이지 빌더와 임의 동적 비즈니스 로직

Exit criteria

  • 고객과 전문가가 서로 다른 시작점과 내비게이션을 가진다.
  • 모든 핵심 페이지가 사용자 질문 또는 업무 결과로 설명된다.
  • Company Data는 정본 탐색의 2차 진입점이며 홈 내비게이션의 중심이 아니다.
  • IA, 두 셸 layout, 페이지 인벤토리와 surface boundary가 연결된 계획 그래프로 검증된다.
