## 포지셔닝 가드레일 (헷갈리지 말 것)

- ❌ "코딩 에이전트가 맥락 없이 일한다 → MCP/컨텍스트 엔지니어링" — **이미 풀린 문제. 덱에 담지 않는다.**

- ✅ **병렬 에이전트 + 무인(사람 개입 없음)** 관점에서 바로 시작.
- ✅ 핵심 인과: **기준 없는 맥락 → 어긋난 판단 → 사람 재개입 → 사람 시간에 묶임 → 무인이 안 됨.**
- ✅ 해결: 이전 의사결정·관계·최신성을 담은 **컨텍스트 지식그래프**가 판단 기준이 됨.

## 2. Problem — "에이전트 팀의 병목은 아직 사람이다"

**UX 진화 카드 (Pair → Agent → 에이전트 팀)**

| 단계 | UX | 한 줄 |
|------|-----|--------|
| Pair | 초기 Cursor — VS Code 사이드바 채팅 | 코드를 보며 1:1로 같이 작업한다 |
| Agent | CLI 에이전트 (Claude Code 느낌) | 개발자는 코드 없이 과업 단위로 맡긴다 |
| 에이전트 팀 | 병렬 에이전트 | deprecated vs 최신 스펙, UI 컴포넌트 깨짐 → 사람 재개입 |

**결론 (3문장):**

1. 에이전트 하나의 과업 작업은 가능합니다.
2. 그러나 팀으로 병렬 실행하면 판단이 갈라지고, 제품의 의도와 멀어지게 됩니다.
3. 다시 사람의 개입이 들어가게 되고, 에이전트를 사람이 직접 관리하게 됩니다. 즉, 사람이 병목이 됩니다.

- (인과) 기준 없는 맥락 → 어긋난 판단 → 사람 재개입 → 사람 시간에 묶임 — 3번 Solution으로 이어짐

## 3. Solution — "OKR부터 배포까지, 제품 맥락을 한 그래프로 관리한다"

**브릿지:** 로드맵 · 리서치 · 이니셔티브 · 설계 · 테스트 · 런북 — 끊기지 않게.

**제품 맥락 체인 (3단계 · 7노드)**

| 단계 | 노드 |
|------|------|
| 방향 | OKR · 로드맵 · 유저 리서치 |
| 실행 | 이니셔티브 · 설계결정 |
| 검증·배포 | 테스트 · 배포 런북 |

비주얼: 가로 체인 + 병렬 에이전트(API/UI/Infra)가 동일 맥락 참조 + 4구성 카드.

**4구성 (과정 관점)**

| 구성 | 역할 | 한 줄 |
|------|------|------|
| 지식그래프 | 맥락 노드·관계·최신성 | 맥락을 관계로 연결 |
| 워크플로우 | 이니셔티브·테스트·배포 절차 | 같은 절차로 일함 |
| MCP | 작업 전 read · 후 write | 외부 컨텍스트 주입 |
| 콘솔 | OKR·로드맵·승인 게이트 | 사람은 방향승인만 |

**결론 (3문장):**

1. 병렬 에이전트가 **같은 제품 맥락**을 봅니다.
2. 구현이 **OKR과 설계 의도**에서 벗어나지 않습니다.
3. 사람은 **방향과 승인**만 하면, 무인 에이전트 팀이 돌아갑니다.

→ Problem(병목=사람)의 정렬된 반대편. 무인 에이전트 개발팀.

## 6. Unique Insight — "무인의 조건은 속도가 아니라 공통 판단 기준"

**브릿지:** 같은 기준으로 판단해야 사람이 빠질 수 있다.

**통념 vs 인사이트 대조 (`InsightContrast`)**

| | 통념 — 더 빨리 짜면 된다 | 인사이트 — 같은 기준으로 판단해야 한다 |
|---|---|---|
| 관점 | 속도·생성량 경쟁 / 흩어진 문서·프롬프트 / 도구가 빠를수록 좋다 | 관계·우선순위·최신성 그래프 / 병렬 에이전트 공유 판단 기준 / 사람은 방향·승인 |
| 결과 | 그래도 **사람이 매번 정렬** — 무인이 안 된다 | 그제서야 **사람이 빠진다** — 무인이 가능하다 |

**클로징:** 이 문제는 사람이 곁에 있을 땐 안 보이고, **무인 병렬일 때만** 드러난다 — 그래서 지금, 우리가.

## 7. Business Model — "맥락 그래프에서 돈을 번다"

- **Open Source** `$0` self-host — 핵심 그래프·워크플로우·MCP (생태계 확산)
- **Cloud SaaS** `$20–199` user/mo — 협업·승인·버전·권한 (**주력**)
- **Enterprise** `$20K–100K+` /yr — 맞춤 워크플로우, SSO·감사로그·VPC·SLA

## 8. Market — "무인 에이전트 개발팀 수요가 시장을 만든다"
