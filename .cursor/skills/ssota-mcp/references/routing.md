# Routing

Generic intent routing is archived. Active routing is limited to project and task context.

| Request | Tool |
|---|---|
| List organizations | `list_organizations` |
| List projects | `list_projects` |
| Fetch project | `get_project` |
| List tasks | `list_tasks` |
| Filter tasks | `query_tasks` |
| Fetch task | `get_task` |
